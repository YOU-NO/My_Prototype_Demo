# 时点库存原型说明

## 原型目的

演示【库存管理】下新增的「时点库存」查询页，以及用来对照的「出入库流水」。时点库存按仓库和会计口径日期，用上月期末库存快照累加入库、出库单明细，得到该日的仓库维度时点在库。

## 页面清单

- 时点库存列表：仓库、SKU、日期筛选，查询、重置、导出。SKU 筛选沿用“SKU + 精确/模糊 + 输入框”的组合样式，支持逗号或换行批量输入。结果按仓库、SKU 展示期初快照库存、历史补录入库、历史补录出库、期间入库、期间出库和时点在库。
- 出入库流水：同一套入库单、出库单拟造数据。可按仓库、SKU、会计口径日期筛选，展示单据类型、业务类型、单据号、会计口径日期和变动数量。
- 导出确认弹窗。
- 页面内提示：未选择条件、缺少期末快照、导出成功。日期范围不再在筛选栏下方常驻说明。左侧菜单可在两个页面之间切换。

本地文件：`docs/prototypes/point-in-time-inventory/prototype.html`

## 交互流程

1. 打开页面后，仓库和日期为空，表格为空。
2. 仓库和日期都选择后点击查询，以原始上月期末库存快照为基准，分别计算快照生成后的历史补录单据和本月期间单据。时点在库为 0 或负数的行仍保留，负数用红色显示。
3. 日期控件最早为 2026-11-01，最晚为 2026-11-05。这是原型假设：上线月份为 2026-10，第一张快照是 2026-10 期末。超出范围的日期在面板里不可选，今日、昨日可用，上周、上月不可用。
4. 选择「筋斗云GLC仓」后查询，提示该仓库缺少 2026-10 期末快照。
5. 点击重置，清空仓库、日期和结果。
6. 有查询结果时点击导出，先确认，再提示导出任务已创建。无结果时导出按钮不可用。
7. 点击左侧「库存日志」，查看同一批入库单、出库单流水；筛选使用会计口径日期，不使用库存变更日志。

万邑通澳洲仓、SKU `S810-ST-PK-UK-170-N` 的演算：

- 2026-10 期末快照：在库 120。
- 2026-11-02 创建、会计口径日期为 2026-10-20 的历史补录入库：+8。
- 2026-11-03 创建、会计口径日期为 2026-10-28 的历史补录出库：-3。
- 2026-11-02 调拨入库：入库 +10。
- 2026-11-03 销售出库：出库 -4。
- 2026-11-04 其他入库：入库 +6。
- 2026-11-05 其他入库：入库 +2。

查询 2026-11-04：

```text
期初快照库存 120 + 历史补录入库 8 - 历史补录出库 3
+ 期间入库 16 - 期间出库 4 = 时点在库 137
```

查询 2026-11-05：

```text
120 + 8 - 3 + 18 - 4 = 139
```

历史补录单据不会再次计入期间入库或期间出库。打开 `prototype.html?state=log` 可直接看到入库单、出库单流水。

万邑通德国仓 `S820BK` 在 2026-11-02 出库 15 后，时点在库可能为负数，列表仍展示该行并用红色显示。

仓库名称、SKU 和产品名称使用现有示例。数量是演算数，不代表真实余额。筋斗云GLC仓用来演示缺少期末快照。查询 2026-11-04 时：

- 万邑通澳洲仓的结果按 SKU 展示期初、入库、出库和时点在库；无期初但期间出现的 SKU 从 0 起算。
- 时点在库为 0 或负数的 SKU 仍展示，负数用红色显示。

## 字段和 mock 数据说明

仓库名称、SKU 和产品名称使用现有示例。数量是演算数，不是真实期末结存。明细见同目录 `mock-data.json`。

## 假设条件

- 原型把上线月份定为 2026-10，只为让 2026-11-05 当天可以选出日期。正式上线月份以实际上线月为准。
- 快照按仓库当地时间每月 1 日 00:00 生成，快照内容为仓库 + SKU + SKU 名称 + 在库库存。
- 期间变动直接取入库单、出库单及明细，使用单据上的会计口径日期；不使用库存变更日志。
- 原始期末库存快照不可被查询过程修改。历史补录单据的识别条件为：单据创建时间晚于对应期末快照生成时间，且会计口径日期早于或等于上月期末。历史补录入库、历史补录出库在查询时基于原始快照动态累加计算。
- 期间入库、期间出库的会计口径日期范围为：大于上月期末且小于或等于查询日期。历史补录单据不得重复计入期间出入库。
- 「筋斗云GLC仓」用来演示快照缺失，不代表该仓库真实没有库存。

## 前端实现提示

- 新页面放在与汇总库存相同的菜单分组，路由和权限单独配置。
- 筛选区沿用 ProTable 的小号搜索栏：控件无独立标题，占位文案为「请选择」；仓库单选、可搜索、可清空；日期为单日选择，带今日、昨日、上周、上月快捷项，并禁用范围外日期。
- 主按钮文案使用「查询」。正式 SearchForm 默认写的是「搜索」，本页需要单独改成「查询」。重置仍带清空图标。
- 筛选栏下方不放日期范围说明。未选条件时只在表格空态和点击查询后的提示里说明。
- 导出沿用汇总库存的二次确认。
- 数量列表头和内容居中展示，时点在库小于 0 时用红色数字。
- 结果表各列支持通过表头分隔线手动拖拽调整列宽。
- 在库列表头提示「时点在库 = 期初快照库存 + 历史补录入库 - 历史补录出库 + 期间入库 - 期间出库」。
- 出入库流水按会计口径日期筛选，入库为正数、出库为负数。
