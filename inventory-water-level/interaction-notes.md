# SKU库存阈值查询原型说明

## 原型目的

本原型用于评审一个独立新页面：`库存阈值`。页面不继续在“汇总库存/库存列表”上堆叠字段，而是聚焦业务快速查询“某仓库 + 某库存层级 + 某整机 SKU”的库存水位、阈值和备货计划已下单未发货数据。

原型为独立静态 HTML，不连接真实接口，不修改生产代码。视觉和交互参考现有 EVA WMS `库存列表`、`备货计划列表`、PMS `产品列表` 的 `main-box`、`table-box`、`ProTable`、Element Plus 按钮、紧凑筛选区、表格密度和弹窗样式。

## 页面清单

- 库存层级树：参考现有库存层级 UI，支持按层级节点切换右侧库存水位范围。
- 库存阈值列表：按库存层级、SKU、水位状态快速查询整机 SKU 库存数据。
- 汇总库存静态页：点击侧边栏“汇总库存”后展示参考截图中的汇总库存表格数据，用于对比现有页面内容。
- 水位详情弹窗：展示库存组成、口径说明和备货计划已下单未发货明细。
- 维护水位阈值弹窗：按仓库 + 库存层级 + 整机 SKU 维护低水位阈值和高水位阈值。
- 导入整机 SKU 水位阈值弹窗：模拟 Excel 批量导入阈值。
- 备货计划明细弹窗：展示正式环境风格的备货计划明细字段。
- 页面口径说明弹窗：说明在库库存、总库存、预计水位等计算口径。

## 关键交互

1. 点击“搜索”：
   - 左侧库存层级树用于限定库存范围；搜索区按产品分类、SKU 精确/模糊、水位状态筛选。
   - 水位状态支持多选，可同时筛选库存过高、库存偏低、正常、未维护阈值。
   - 产品分类下拉取值与 SKU 列表保持一致，包含整机、配件类、POP、赠品、虚拟产品、裸机、半成品、POP半成品。

2. 点击左侧库存层级树：
   - 点击“全部”或“公共”时，右侧展示全部库存层级数据。
   - 点击仓库节点时，右侧展示该仓库下所有库存层级数据。
   - 点击库存层级叶子节点时，右侧仅展示该库存层级数据。

3. 点击表格行调拨在途或备货已下单未发货数量：
   - 点击调拨在途数量时，打开“调拨在途明细”弹窗，样式参考正式环境，包含业务单据号搜索、明细表格和分页。
   - 点击备货已下单未发货数量时，打开“备货计划明细”弹窗，字段包含计划单号、状态、始发仓、目的仓、SKU、SKU下单数量；状态统一展示为“待提交调拨发货”。

4. 点击表格行“编辑”：
   - 打开阈值维护弹窗。
   - 可维护低水位阈值和高水位阈值。
   - 保存时校验两个阈值必须为正整数，且低水位阈值小于高水位阈值。
   - 保存后重新计算水位状态。

5. 点击“导入阈值”：
   - 展示模板字段：仓库、库存层级、SKU、产品分类、低水位阈值、高水位阈值、备注。
   - 原型模拟仅允许导入产品分类为“整机”的 SKU。

6. 点击侧边栏“汇总库存”：
   - 切换到汇总库存静态展示页。
   - 表格字段参考正式环境汇总库存页面，包括仓库名称、SKU、产品名称、总库存、可用、锁定、调拨在途和备注。

## 字段和口径说明

- `productType`：产品分类，取值与 SKU 列表产品分类保持一致。
- `levelName`：库存层级名称，来自库存层级树中可存货节点。
- `levelPath`：库存层级路径，用于展示当前行所在仓库和层级。
- `availableQty`：可用库存，来自 EVA 库存数据。
- `lockedQty`：锁定库存，来自 EVA 库存数据。
- `onroadQty`：调拨在途，来自调拨在途数量。
- `inStockQty`：在库库存，等于可用库存 + 锁定库存，对应汇总库存现有“总库存”口径。
- `totalStockQty`：总库存，等于在库库存 + 调拨在途，是本新页面新增综合水位字段。
- `orderedUnshippedQty`：备货计划已下单未发货数量，用于辅助判断未来水位。
- `expectedStockQty`：预计水位，等于总库存 + 备货计划已下单未发货。
- `lowThreshold`：低水位阈值。
- `highThreshold`：高水位阈值。
- `waterLevelStatus`：水位状态。

## 状态判断

- 未维护阈值：低水位阈值或高水位阈值为空。
- 库存过高：总库存 > 高水位阈值。
- 库存偏低：总库存 < 低水位阈值。
- 正常：总库存位于低水位阈值和高水位阈值之间。

## 产品假设

- 新页面建议菜单名为“库存阈值”，放在 WMS 库存管理下，与“汇总库存”“层级库存”并列。
- 页面支持通过产品分类筛选 SKU，业务可选择“整机”查看整机 SKU 的库存水位。
- 本原型将高低水位判断口径设为“总库存 = 在库库存 + 调拨在途”。这与此前“当前库存 = 可用 + 在途”的库存预警口径不同，需要在 PRD 中与业务确认最终判断口径。
- 备货计划已下单未发货不直接并入“总库存”，但进入“预计水位”，用于提示未来到货后可能超高。
- 汇总库存原有“总库存 = 可用 + 锁定”的历史口径在本页面改名展示为“在库库存”，避免与新增“总库存 = 在库库存 + 调拨在途”混淆。

## 前端实现提示

- 可新增 WMS 前端页面，例如 `xzy-erp-ui/src/views/wms/wholeMachineInventoryWaterLevel/index.vue`。
- 页面建议采用左侧库存层级树 + 右侧 `ProTable` 列表布局，树数据可复用库存层级接口。
- 列表建议继续复用 `ProTable`，搜索区配置 SKU、产品分类、水位状态。
- 产品分类筛选可复用 PMS SKU 的 `skuType` 字段，整机值在现有代码中可参考 `warehouseProductMap/dialog.vue` 对 `skuType === "1"` 的判断。
- 库存层级树可参考 `xzy-erp-ui/src/views/wms/inventorylevel/index.vue`，并复用 `warehouseGetTreeListByWhId` 或 `getLevelTreeApi` 类接口。
- 在途明细弹窗可参考 `xzy-erp-ui/src/views/wms/inventory/detailDialog.vue`。
- 备货计划已下单未发货建议由后端按目的仓 + SKU 聚合返回，避免前端跨模块拼接。
- 阈值导入可复用项目已有 `ImportExcel` 组件模式，并增加导入批次、失败数据下载和审计记录。
