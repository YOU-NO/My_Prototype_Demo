# 亚马逊平台报告高保真原型说明

## 原型目的

将 Axure 线框（`docs/Eva_inventory_report` 中的库存分类明细报告、库存汇总报告、仓库报告配置）落地为贴近 EVA 正式环境风格的可交互 HTML 原型，便于产品/研发评审页面布局、字段分组色、筛选与解析/生单操作反馈。

数据来源：
- 页面结构：`库存分类明细报告.html`、`库存汇总报告.html`、`仓库报告配置原型图.html`
- 样例填充：`库存分类明细示例.html`、`库存汇总报告示例.html`、`报告解析与字段识别.html`
- UI 风格：正式前端 `LayoutVertical` / `SubMenu` / `element.scss` / `menu.ts`，以及已有 `docs/prototypes/inventory-water-level/prototype.html`、财务域 `financing/salesPlatform/*` 列表页（`main-box` + `table-box` + `ProTable`）

原型为独立静态 HTML，不连接真实接口，不修改生产代码。

## UI 对齐说明（相对 Axure / 初版原型）

- 去掉 Axure 顶栏「首页 | 财务 | 产品 | …」，改为正式纵向布局：左侧 `aside-box` 210px + 右侧内容区。
- 侧栏复刻 `el-menu`：一级带 SVG 图标与展开箭头，子菜单缩进，激活态浅蓝底 + 主色字 + 左侧 4px 竖条；菜单项高度 50px。
- 菜单内容：`销售平台报告` 下同级 `Coupang平台报告`、`亚马逊平台报告`（均可点击展开/收起）；`平台仓库存报告配置` 与 `销售平台报告` 同级；再同级 `财务推送任务`。已有三个亚马逊销售报告放在 `亚马逊平台报告` 下。
- 内容区按 `main-box` / `table-box`：无独立标题卡片；筛选区无边框阴影；工具按钮在表格 toolbar（导出用 plain 主色风格）。
- 筛选项采用正式列表常见占位下拉（首项为字段名，空值=全部）。

## 交互流程

### 列表页（明细 / 汇总）

1. **搜索**：按是否异常、是否可售、站点、单据号、平台/系统 SKU、大场景、业务类、当地日期过滤。
2. **重置**：清空筛选并恢复全量。
3. **导出**：toast「已导出 N 条」。
4. **批量导入更新**：弹窗拖拽上传区，确认后 toast 成功。
5. **更新后报告生成单据 / 更新单据生成**：对已解析且无单据号的行生成 `IA`/`IR` 单号。
6. **表头 tip**：`New Quantity`、`是否月末报告` hover 显示字段说明。

### 配置页

1. **搜索 / 重置 / 导出**：按站点、大场景、业务类过滤。
2. **新增配置 / 编辑**：抽屉表单保存回写表格。
3. **删除**：二次确认后移除。

## 字段与 mock 说明

- 完整列定义与样例行见同目录 `mock-data.json`。
- 明细样例含：JP 报废成功行、SA 未维护货品映射异常行、US 收货多单号行。
- 汇总样例含：Amazon_SA / Amazon_JP / Amazon_US 月末 Unknown Events 行。
- 配置样例含：备货接收、找回、报废、Unknown Events（Inventory Summary）规则。
- 为演示「解析 / 生单」，原型内联数据在原 mock 基础上各增加 1 条待解析行。

### 表头颜色

## 假设条件

1. 「亚马逊平台报告」挂在正式「销售平台报告」下，作为新增二级目录；落地时菜单权限与路由需产品确认。
2. 仓库中尚无同名正式前端页，视觉对齐现有财务报告列表页与 LayoutVertical 侧栏，而非某一生产页增量改造。
3. 侧栏不再提供「报告解析配置」入口；明细/汇总列表也不再放置「报告解析」按钮。
4. 分类明细、库存汇总不再单独展示「生成单据号2」；多张单据号合并写入「生成单据号」，逗号分隔。
5. 已有销售报告的样例行复用本期库存样例中的 SKU/站点（`S710-ST-GY-US-326-AZB`、`T910BG-SA`、`Amazon_US` 等）及正式字典店铺名（`Coupang_海外`、`Coupang_海外2店`）；订单号/单号为演示数据，非正式库导出。
6. 侧栏「亚马逊发货运输报告」按正式环境截图命名；对应代码页 `amazonShipmentReport` 的 ProTable title 为 `Amazon订单报告`。

## 前端实现提示

- 宽表建议 `ProTable` + 横向滚动；表头背景按字段分组配置。
- 解析规则来自「平台仓库存报告配置」；站点+MSKU 映射货品、是否可售匹配良/不良品仓。
- `New Quantity`：已生单据时数量变更写入该字段；未生单据可直接改 `Quantity`。
- 一条明细可对应多个单据类型/单据号（逗号分隔）。
- 打开方式：浏览器直接打开 `prototype.html`。
